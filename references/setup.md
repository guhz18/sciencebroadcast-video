# 自动配置视频制作环境

用户要求制作视频，即开始在有权限的执行环境内配置本次制作所需的免费工具和项目依赖。Agent 负责执行命令、修复常见失败、验证与复现。默认只配置实际制作环境；只有用户要求在其本机制作且具备本机执行能力，才安装到本机。准确报告安装位置。

## 执行顺序

1. **盘点**：先读取 [run-history.md](run-history.md) 所述历史记录。对于匹配且仍可用的已验证环境，只做轻量检查，跳过重复安装和完整样片验证。首次或环境变化时，检查操作系统、架构、网络、可写目录、现有工具版本和可用授权服务。读取已有项目的锁文件与安装说明。制作启动时就检查关键依赖，可同时推进脚本与科学核验。
2. **选最小工具链**：通常是可输出音频的自动语音工具、一个主渲染器、FFmpeg/ffprobe、支持中文和数学符号的字体。用 Remotion 时补 Node、包管理器及渲染浏览器；用 Manim 时补隔离 Python 环境和确实需要的原生库、公式排版依赖；只有三维镜头需要时才加 Blender，按 [math-and-particles.md](math-and-particles.md) 检查无界面渲染、实例化和缓存。混音使用 FFmpeg 的 sidechaincompress、amix、loudnorm，先验证过滤器可用。选用的第三方技能按需加载。
3. **实际安装**：优先复用健康的已安装工具和缓存。缺什么装什么，使用官方包源或发行包，锁定兼容版本。优先项目内环境、用户级安装或可移植工具；遵循已有锁文件。核对来源及许可证，审阅会执行的安装命令。项目内常规免费安装直接完成，别把安装教程当交付。需要管理员操作时，先找用户级替代；不索要密码，不绕过权限。
4. **验证成片链**：用实际选定的渲染器跑一段短镜头，检查中文/公式字体、帧与合成；检查自动配音凭据和现有额度，有授权时做最小试听，将真实音频合入样片并用 ffprobe 核对。版本查询只证明工具存在。记录实际验证过的能力、锁定版本、执行位置和复现命令。
5. **处理故障并继续**：按具体错误修复路径、版本或依赖；网络或权限阻断时，尝试可信的缓存、官方发行包、项目内安装或等价工具。优先保证科学表达、自动旁白和交付规格。尝试合理替代后仍受阻，报告精确缺项与受影响阶段，继续独立工作。
6. **必要时交接**：仅当需要新增付费、本人登录或授权、验证码、系统权限，或确实没有执行入口时，让用户完成最小一步。若涉及付费，给出具体服务、已核验价格或预计用量、已完成的准备及付费后的续做动作。已有授权预算内直接推进。不把普通安装、终端操作和排错转交给用户，不让用户在聊天里发送密钥。
7. **接回制作**：用户完成必要步骤后，从已保存的状态恢复，复核服务可用性，继续样片、全片渲染与质检。自动配音通道全受阻时可交付待自动配音预览；只有用户明确要求才进入真人录音路线。

把每项依赖的用途、版本、来源、安装位置、验证结果与剩余阻碍写回持久历史。区分“已检测”“已安装”“已通过样片”。不在预览或生产记录中暴露凭据。
